# 策略、市场和资金口径

## 将规则转为可执行约定

写清每个指标的数据源、参数与确认时刻。区分信号 K 的开盘时间、收盘确认时间、订单提交时间和真实模拟成交时间。成交可能是信号收盘、下一根开盘或后续限价触发，不能统一当作关键 K 收盘成交。

明确多空、进场、出场、止损止盈、追踪或移动规则、加仓减仓、分批平仓、反手、信号有效期及重复信号处理。没有固定止损止盈的策略无需补造。背离、分型和转折点使用确认时刻，不能回填到尚不知道结果的过去 K。

用户已给过规则且本次沿用时，复用已确认部分；新策略不能自动继承旧策略等待状态、RSI 区间或阴阳线要求。遇到缺项时，只询问会改变结果的内容，不为每次回测增加批准流程。

## 每笔金额的含义

| `sizing.mode` | 含义 | 线性合约示意 |
| --- | --- | --- |
| `fixed_margin` | 每笔固定保证金 | 名义仓位 = 保证金 × 杠杆 |
| `fixed_notional` | 每笔固定名义金额 | 保证金 = 名义金额 ÷ 杠杆 |
| `quantity` | 固定币、股或合约数量 | 名义金额 = 数量 × 价格 × 合约乘数 |
| `equity_percent` | 按当前权益比例 | 必须再写明比例用于保证金还是名义金额 |
| `risk_amount` | 每笔最大计划亏损 | 需止损距离、费用和合约规则反推数量 |

`value` 与 `description` 明确单位和含义。杠杆、数量单位、合约乘数、最小交易数量与金额、账户可用保证金由对应市场决定。数量包含杠杆后，盈亏不再额外乘一次杠杆。

本金、名义仓位、保证金、现金余额、已实现损益和账户权益是不同数。用户要求的“这单过后金额”要说明是平仓后已实现余额、现金还是包括其它持仓浮盈亏的账户权益。资金曲线必须对应同一口径。

固定金额不随盈亏复利。权益比例通常随权益变化，但仍以用户定义为准。风险金额与保证金不可互换。多持仓、分批成交或有资金进出时，记录事件账本并引用对应退出事件的账户快照。

## 数据和市场适配

| 市场 | 需要明确的条件 |
| --- | --- |
| 加密现货 | 交易所、交易对、计价资产、是否允许融券、手续费资产 |
| 永续合约 | 合约类型、资金费、标记价格、保证金模式、强平与维护保证金是否模拟 |
| 股票 | 交易日历、停牌、T+1、涨跌停、整手、做空限制、复权与税费 |
| 商品或金融期货 | 具体合约、乘数、交易时段、换月、保证金与到期规则 |
| 外汇或其它品种 | 报价单位、点值、时段、融资成本、账户币种换算 |

只有数据和实现覆盖的机制才能写成已模拟；其余写入 `meta.limitations`。适配器不支持时，修改实现或选用合适引擎，不用其它市场的撮合规则代替。

历史精度或费用无法确认时，明确使用的假设。基于真实数据与专门生成的测试行情要标明用途，不能把合成测试的收益当成历史市场表现。
