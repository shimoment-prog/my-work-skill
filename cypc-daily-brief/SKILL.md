# 长江电力日报

用户说「长江电力日报」「长电日报」「600900 日报」「长江电力报告」时，读本技能和 [reference.md](reference.md)，按 [template.md](template.md) 现取数、现填表。不要靠对话记忆里的旧数字。

## 何时使用

- 长江电力 / 长电 / 600900 的日报、水文、电量、利率息差、电价、利润
- 要求「按模版出数据」或更新上一份长电日报

## 产出

每次都写两份（本地，未要求则不 commit）：

1. Markdown：`/Users/richao11/myproject/my-quant/report/cypc-日报-YYYY-MM-DD.md`
2. Canvas：`/Users/richao11/.cursor/projects/Users-richao11-myproject-my-quant/canvases/cypc-daily-YYYY-MM-DD.canvas.tsx`

章节顺序固定，不要增删、不要调换：

1. 日度水文 + 季度来水
2. 电量季度数据
3. 利率和息差
4. 电价和财务支出
5. 季度利润（已公告）
6. 用发电量测算的最新未出季报利润

回复用简体中文。先给一句话结论，再给路径链接。文末写「不构成投资建议」。

把 [template.md](template.md) 的占位符换成当天核过的数。

## 取数顺序

```
进度:
- [ ] 现价（东财 1.600900，f43/100）
- [ ] 日度水文（水位、入库、出库；没有就不编）
- [ ] 最新发电量/来水公告（同比用原文，环比自己除）
- [ ] 中债十年期（官网日终；盘中报价单列）
- [ ] 股息率 = 上一完整年度 DPS / 收盘价；息差 = 股息率 − 十年期
- [ ] 财务费用、营收（最新季报/中报）
- [ ] 已公告季度归母
- [ ] 最新一季若利润表未出：按 reference 桥梁测算，标明测算
```

## 硬规则

- 未公布的利润、电价、财务费用不要编成公告数。测算必须写「测算」和假设。
- 来水只认公司公告的两个断面：乌东德、三峡。中间四座不单列来水。
- 同比：公告原文。环比：当季绝对数相除。
- 十年期：中债国债收益率曲线日终（约 17:30）。英为等盘中报价可作近况，不得替代日终点。
- 综合电价折算 = 营业收入 ÷ 境内六座发电量，注明不是年报「上网电价」。
- 东财：价格 f43/100，涨跌幅 f170/100。
- 不给买卖建议，不把 76bp 息差反推价格当目标价。

## Canvas

只从 `cursor/canvas` 导入。无渐变、无 emoji、无阴影。一句话 Callout + 六段。提到 canvas 时用完整绝对路径 markdown 链接。

每次日报 canvas **必须**带这三组图，不要缩成一张合图：

1. **来水**：三峡、乌东德分开，各一张本年 vs 去年绝对量柱。不要画同比%/环比% 对比图。
3. **利率和息差**：近五年（约 2021 末至今）——十年期与静态股息率同图双线、息差（股息率−十年期，可画 76bp 参考线）。不要画息差变化柱。季末点 + 关键断点（如 2024/8）+ 最新日终。取数见 [reference.md](reference.md)。
6. **利润**：两张图。① 今年各季归母 vs 去年各季（含去年四季度）；已公告用 `info`，电量测算季用 `warning`，不要把测算画成公告。② 去年全年归母 vs 今年已公告累计归母（测算不计入）；图下注明已公告覆盖到哪一季、占去年全年多少。
