## 7. 未来走势

四条情景，股价带都写成区间。概率是判断，加总约 100%。上下沿沿用下面四档，不另起一套。股价 = 上一完整年度 DPS /（最新十年期日终 + 该情景息差）。十年期变了，只改每档对应的息差，以及现价落在哪一档。区间不是目标价。76bp 旧锚不进这张表，不算成价格。

| 情景 | 股价带（元） | 对应什么 | 概率 |
|---|---|---|---|
| 主线 | 29–30 | 现价是否已在带内。对着当天十年期大约多少 bp。未出季归母是否在测算中枢 | |
| 再下一档 | 27–28 | 息差走到大约 200bp，或归母靠近测算下沿 | |
| 收到约 150bp | 31–32 | 息差收到大约 150bp，或归母靠近测算上沿 | |
| 回到 6 月末 | 26–27 | 十年期回到 2026-06-30 的 1.733%，息差回到当时约 205bp | |

主线写在第一行，是现价所在的那一档。现价离开 29 元，主线改到 27–28，29–30 改成收回。写明下一份季报或十年期怎样变，会把概率从主线挪走。
