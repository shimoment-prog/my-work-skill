# 个股市盈率

用户要看一只股票的滚动市盈率、近五年中位数，或同业市盈率时，读本技能和 [reference.md](reference.md)。数字现取，不沿用对话里的旧倍数。

历史分位只说明这只股票自己过去五年的位置。它不改估满、偏低、偏高。同一天若已有个股日报，日报的判断照旧，本技能只加一句对照。

## 产出

一份 canvas，不另写日报，未要求则不 commit。

路径：当前工作区的 `canvases/{code}-pe-YYYY-MM-DD.canvas.tsx`。在 my-quant 里是 `/Users/richao11/.cursor/projects/Users-richao11-myproject-my-quant/canvases/`。

回复用简体中文。先写中位数和今天的滚动市盈率，再写同业落在哪一档。文末「不构成投资建议」。提到 canvas 时用完整绝对路径。

## 取数

```
进度:
- [ ] 确认代码和上市地。同名多地只做用户说的那一个
- [ ] A 股跑 scripts/pe_history.py。港股按 reference 自建，不用财报行上复制的 PE_TTM
- [ ] 现价单独折算，不放进中位数样本
- [ ] 同业：产品相近的国内和海外各一组，表内每行带总市值。用户明确不要同业时跳过
- [ ] 滚动利润里的一次性收入写进第一句
```

A 股：

```bash
python3 scripts/pe_history.py 300502 --live-price 172.55
```

脚本输出是中位数、分位、分年、月末序列的唯一口径。不要另算一套中位数。`--live-price` 用刚取到的盘中价。样本只含已收盘的交易日。

## 硬规则

- 中位数是样本里每个交易日等权，不是各年中位数再平均。图上的参考线是这个中位数，不是月线自己的中位数。
- 今天若在交易，最后一点是盘中：最后收盘的 PE_TTM × 现价 / 最后收盘价。这一点不进样本。停牌或已收盘就用最后收盘，不要再折算。
- A 股图用脚本的 PE_TTM。静态市盈率（PE_LAR，分母是上年年报）另起一句，不和滚动线画在一起。
- 动态市盈率（半年或前三季度年化，行情里的 f9）不进图，不进中位数。
- 滚动利润含首付款、许可收入、公允价值或价格暴利时，第一句写明低倍数来自分母。
- 情景倍数不画进历史折线。它和滚动倍数明显不是一档时，同业图里可以单列一根，标注「情景，不是滚动」。同一档就只在句子里对照。
- 历史分位不写成偏低或偏高，也不改同一天日报的判断。
- 未注销的回购和库存股不从股本里扣。港股行情股本若已扣库存股，图仍用已发行股本，两个倍数都写，中位数只用自建序列。
- 取不到的同业省略，写「没有取到」，不编倍数。亏损写「亏损」，不画负柱。
- 不给买卖建议。

## 同业

默认要。国内、海外各 4 到 8 家，按产品而不是按大行业。每一行写明和本公司的关系（同一产品、器件、相邻），并写总市值。控股子公司不进排序，单独一句，这句也写上市值。存储公司先放三星电子、SK 海力士、美光和已上市的长鑫科技，MCU 只作相邻。

总市值用行情里的总股本乘价格，不用流通市值。未注销回购和库存股不从总市值里扣。A 股写亿元人民币，港股写亿港元，美股写亿美元，韩国写亿韩元。不把不同货币折成同一种。价格、滚动市盈率和市值用同一时点；对不上就改到同一次行情，不留旧价格配新市值。

时点写清楚：A 股和港股用本次盘中，美股未开盘用最近收盘。口径见 [reference.md](reference.md)。

## Canvas

只从 `cursor/canvas` 导入。无渐变、无 emoji、无阴影。

顺序：

1. 标题写明股票和「滚动市盈率」。副标题写来源、样本起止、交易日数、盘中时点。
2. Callout 写中位数、今天的倍数、低于或等于今天的交易日占比。一次性利润或情景对照放在这句里。
3. 四格：中位数、盘中倍数和价格、分位、最低到最高及日期。
4. 折线用每个交易日，同时画滚动市盈率和股价。滑动时提示里要同时出现那一天的倍数和收盘价，所以放在同一张图、两根线，不要收成月末。纵轴只能共用，图注写明单位不同，高度不能当成同一单位。参考线只标市盈率中位数。股价用估值表里的收盘价，不是前复权。最后一点若是盘中，股价用折算市盈率时的那个现价，日期单独标出。
5. 分年表：年、交易日、中位数、最低、最高、年末或最新收盘。不满一年写明天数。
6. 同业柱只含正的滚动市盈率，按倍数从低到高。情景柱用另一种颜色，且仅在和滚动不是一档时出现。
7. 国内表、海外表。列至少有公司、关系、价格、滚动市盈率、总市值。亏损和滚动为负的放在表里，不放进柱状图，市值仍写。

图注写明盘中点不在中位数样本里。
