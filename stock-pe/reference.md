# 个股市盈率 · 口径

## A 股历史

东方财富 `RPT_VALUEANALYSIS_DET`。

- 列：`TRADE_DATE`、`CLOSE_PRICE`、`PE_TTM`、`PE_LAR`
- 过滤：`SECURITY_CODE` 六位代码，`TRADE_DATE` 从今天往前五年
- 分页：`pageSize=500`，按日期翻完
- `PE_TTM` 缺失或小于等于 0 的交易日拿出样本，在结果里计数，不参与中位数
- `PE_LAR` 是上年年报的静态市盈率，单独统计，不和滚动线混画

中位数和分年中位数都用同一算法：排序后取位置 `p × (n - 1)` 的线性插值。`p = 0.5` 是中位数。`scripts/pe_history.py` 已经这样算，不要改成「各年中位数的中位数」，也不要改成只取中间那一天。

现价折算：`最后收盘 PE_TTM × 现价 / 最后收盘价`。用现价去对行情商的滚动市盈率，相差超过 0.2 倍时两个数都写，图用折算值。

现价用腾讯行情，GBK。深圳 `sz`，上海 `sh`。字段：现价、昨收在名称和代码之后。时点用行情里的时间，盘中就写盘中。

## 港股历史

财报接口 `RPT_HKF10_FN_MAININDICATOR` 的 `PE_TTM` 是当前倍数复制到每一行，不能当历史。`EPS_TTM` 也只在报告期更新。

自建：

```
滚动市盈率 = 不复权收盘价（港元） × 当时已发行股本 × 当日港元兑人民币收盘 ÷ 当时已公布的近十二月归母（人民币）
```

- 股价：东方财富日线 `secid=116.{五位代码}`，`fqt=0`，`klt=101`。不用前复权。
- 汇率：腾讯 `whHKDCNY` 日线收盘。当天没有就用不超过当天的最近一个收盘。
- 归母用公告里的本公司权益股东应占溢利。中期是上半年，年报是全年。下半年 = 全年 − 上半年，写明是相减。
- 业绩若在收盘后公布，滚动利润从下一交易日切换。年报公布后，近十二月 = 该全年。中期公布后，近十二月 = 上一个下半年 + 本年上半年。
- 公司不披露单季就不要拆季度。
- 股本用已披露的发行台阶（认购、配售完成日）。公告写「约百分之几」回推的股本要标明，并说明大约 1% 的误差不改中位数所在的整数档。未注销回购不扣。

行情商当天打印的倍数可以并列，不放进自建样本。

## 同业现价倍数

一次取完，保证时点一致。

```
https://push2.eastmoney.com/api/qt/ulist.np/get?fltt=2&fields=f12,f13,f14,f2,f3,f9,f20,f115&secids=
```

| 市场 | secid | 用哪一列 |
|---|---|---|
| 深圳 | `0.{代码}` | `f115` 滚动。`f9` 是动态，不用。`f20` 是总市值 |
| 上海 | `1.{代码}` | 同上 |
| 港股 | `116.{五位代码}` | `f9` 与 `f115` 通常相同，当作行情滚动。与自建序列不同时，表内主体用自建。总市值用 `f20` |
| 纽交所 | `106.{代码}` | `f115` 滚动，`f20` 总市值 |
| 纳斯达克 | `105.{代码}` | 同上 |
| 韩国 | `177.{代码}` | `f115` 滚动，`f20` 总市值。存储用主板：三星电子 `177.005930`，SK 海力士 `177.000660`。不用杠杆 ETF，也不用 ADR 代替主板 |

`f20` 是总市值，不是流通市值。表写原币：A 股亿元人民币，港股亿港元，美股亿美元，韩国亿韩元。不折算。东方财富接口断开时，用腾讯行情同一时点补，不要留空市值：

- A 股 `sh` / `sz`：`~` 分段后第 45 段是总市值，单位亿元人民币。第 44 段是流通市值，不用。
- 港股 `r_hk`：第 45 段是总市值，单位亿港元，等于股价乘已发行股本。
- 美股 `us`：第 45 段是总市值，单位亿美元。

分段从 0 起数。价格、滚动市盈率和市值必须来自同一次返回。

`f115` 为负：亏损。动态为正、滚动为负时，只写滚动为负，动态可以附在同一格，不能当作滚动。

雅虎行情经常 403，不要改去雅虎补数。东方财富没有这只股票就省略。

美股在北京时间上午通常未开盘，表头写最近收盘。不要把美股涨跌幅说成和 A 股同一盘。

公司做存储（DRAM、NAND、NOR）时，同业先放已上市的三星电子、SK 海力士、美光，以及长鑫科技（688825，长鑫存储上市主体）。MCU、功率、接口只放在相邻一列，不能代替这几家。长鑫 2026-07-27 才上市，没有五年序列，只放当期滚动市盈率。参股不改变它是独立上市公司。

## 和日报的分工

个股日报的估满、偏低、偏高对着写明的利润情景。本技能的中位数对着过去五年的滚动市盈率。

两句可以同时出现，例如：滚动 16 倍，五年中位数 44 倍；日报仍按全年情景判断估满。不要用分位改日报的那句判断。

情景倍数和滚动倍数接近，通常是因为近四季利润已经接近情景。写出来，避免读者以为用了两套利润。
