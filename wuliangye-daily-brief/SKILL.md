# 五粮液日报

用户说「五粮液日报」「普五日报」「000858 日报」「五粮液报告」时，读本技能和 [reference.md](reference.md)，按 [template.md](template.md) 现取数、现填表。不要靠对话记忆里的旧数字。

## 何时使用

- 五粮液 / 普五 / 000858 的日报、批价、终端价、开瓶、动销、渠道库存、归母、回款、合同负债
- 要求「按模版出数据」或更新上一份五粮液日报

## 产出

每次都写两份（本地，未要求则不 commit）：

1. Markdown：`/Users/richao11/myproject/my-quant/report/wuliangye-日报-YYYY-MM-DD.md`
2. Canvas：`/Users/richao11/.cursor/projects/Users-richao11-myproject-my-quant/canvases/wuliangye-daily-YYYY-MM-DD.canvas.tsx`

章节顺序固定，不要增删、不要调换：

1. 飞天一批、普五一批、一批利润、普五终端（上年 1 月起）
2. 今年开瓶、动销
3. 今年渠道库存
4. 归母利润（已公告；未出季测算）
5. 今年回款和合同负债

回复用简体中文。先给一句话结论，再给路径链接。文末写「不构成投资建议」。

把 [template.md](template.md) 的占位符换成当天核过的数。

## 取数顺序

```
进度:
- [ ] 现价（东财 0.000858，f43/100，未复权）
- [ ] 飞天散瓶一批、普五一批：上年 1 月至今能核到绝对价的时点
- [ ] 普五终端：酒价内参成交均价，序列起点之前不补
- [ ] 一批利润 = 普五一批 − 889
- [ ] 今年开瓶、动销（公司表述与券商渠道分开）
- [ ] 渠道库存（经销商月数、终端、厂内成品分开）
- [ ] 已公告季度归母（2025 年起用差错更正后口径）
- [ ] 最新一季利润表未出：按 reference 桥梁测算，标明测算
- [ ] 销售回款、应收款项融资、合同负债、监管商品款项
```

## 硬规则

- 未公布的利润、吨价、费用不要编成公告数。测算必须写「测算」和假设，并给中枢和区间。
- 2025 年各季归母、营收用差错更正后的数。调整前的数只可作对照，不进主表。
- 飞天图用当年散瓶一批。只有原箱价的日期不画进散瓶线。
- 普五终端只用酒价内参全国成交均价。该序列 2025-11-10 才开始，上年 1–10 月不接京东到手价。标题没给绝对价的日期不画。
- 一批利润的图始终对 889。阶段性开票价或补贴后成本另起一句，不换图的锚。
- 浓香自营品牌开瓶扫码不是普五。渠道帖里的瓶数标明转述，不升格成公司公告。
- 省份动销样本不能加成全国。申万「占全年任务 10%–15%」和「1–2 个月」是同一量级的两种说法，不要当成两套库存。
- 销售回款只计「销售商品、提供劳务收到的现金」。新开银行承兑看应收款项融资，和现金分开写。
- 合同负债和监管商品款项是两笔已收款未确认，必须并列。基酒吨数不拿来和渠道月数比。
- 合同负债领先的是后面一到两个季度的收入，不是当天股价。不把余额差乘上市盈率当目标价。
- 东财：价格 f43/100，涨跌幅 f170/100，股价 `fqt=0` 未复权。
- 不给买卖建议。

## Canvas

只从 `cursor/canvas` 导入。无渐变、无 emoji、无阴影。一句话 Callout + 五段。提到 canvas 时用完整绝对路径 markdown 链接。

每次日报 canvas **必须**带这些图，不要缩成一张合图：

1. **价格**：四张分开的绝对价折线，起点都是上年 1 月（终端序列晚于这个起点就从序列第一点画，图注写明）。飞天一批、普五一批、一批利润（对 0 和语义上的 889）、普五终端。不要画同比%图。
4. **归母**：两张柱。① 今年各季 vs 去年各季（含去年四季度）；已公告用 `info`，测算季用 `warning`，不要把测算画成公告。② 去年全年 vs 今年已公告累计（测算不计入）；图下注明覆盖到哪一季、占去年全年多少。
5. **回款和合同负债**：销售回款画今年各季 vs 去年同季的绝对额。合同负债画季末余额；监管商品款项另列，不并进合同负债。
