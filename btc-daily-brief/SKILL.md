# 比特币日报

用户说「比特币日报」「BTC 日报」「比特币简报」「四层简报」时，读本技能和 [reference.md](reference.md)，按 [template.md](template.md) 现取数、现填表。不要靠对话记忆里的旧数字。先找到 `report/btc-四层简报-*.md` 里日期最近的一份，对照表用那一天，不另起框架。

## 何时使用

- 比特币 / BTC 的日报、四层简报、ETF 流向、贴现率、油价
- 要求「按模版出数据」或更新上一份比特币简报

## 产出

每次都写两份（本地，未要求则不 commit）：

1. Markdown：`/Users/richao11/myproject/my-quant/report/btc-四层简报-YYYY-MM-DD.md`
2. Canvas：`/Users/richao11/.cursor/projects/Users-richao11-myproject-my-quant/canvases/btc-daily-YYYY-MM-DD.canvas.tsx`

章节顺序固定，不要增删、不要调换：

1. 贴现率
2. 机械卖盘
3. 叙事
4. 流动性

开头写一句话、现价、相对上一份简报。结尾写未来 24–48 小时什么会改判断。这不是第五层。

回复用简体中文。先给一句话结论，再给路径链接。文末写「不构成投资建议」。

把 [template.md](template.md) 的占位符换成当天核过的数。

## 取数顺序

```
进度:
- [ ] 上一份本地简报的日期和四层结论
- [ ] 现价（CoinGecko，写北京时间）
- [ ] 十年期 / 两年期 / 三十年期日终；盘中单列
- [ ] 下一次 FOMC 的加息概率（写明会议日）
- [ ] 最近一次已公布的 CPI 或 PCE；没公布就写未公布
- [ ] 布伦特近月收盘，写明合约月
- [ ] Farside 美国现货比特币 ETF；横杠日不进合计、不进图
- [ ] 叙事只写已披露的囤币和法案动作
- [ ] 信用利差或美元；没有危机式报道就写没有，不编利差
```

## 硬规则

- 未公布的 ETF 全日、CPI、PCE 不要编成已公布。Farside 上 IBIT 还是横杠的交易日，不画进柱、不进区间合计。已列出的发行方小计单独写「未齐」。
- 十年期、两年期、三十年期优先美国财政部平价曲线日终。彭博、CNBC 盘中报价可作近况，不得替代日终。
- 加息概率写 CME FedWatch、哪一次会议、取数时点。盘中冲高又退回的，两个数都写。
- 油写布伦特、合约月份、收盘。WTI 只有在解释价差时才出现。
- 价格用现货美元。整数关口是观察线，不反推目标价。
- 叙事层只收已披露事实。没有新的囤币或投票，就写没动。
- 流动性先判断是利率与油的清算，还是信用冻住。没有利差数据就不要编一个数。
- 不给买卖建议。

## Canvas

只从 `cursor/canvas` 导入。无渐变、无 emoji、无阴影。一句话 Callout + 四层。提到 canvas 时用完整绝对路径 markdown 链接。

每次日报 canvas **必须**带：

1. **ETF**：最近若干个完整交易日的净流入柱，单位亿美元。未齐的日期不出现在横轴。不要画累计变化率。
2. **四层表**：贴现率、机械卖盘、叙事、流动性。每层有现在的读数，和改判断的线。

十年期、布伦特、现价若各能核到至少 4 个时点，再各加一张绝对水平折线。不够 4 个点就用表，不编点。
