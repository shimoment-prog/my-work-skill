## 1. 当前估值：高还是低

判断：**〔偏低 / 估满 / 偏高〕**。对着的利润是〔情景名，例如全年归母〕**〔〕亿元**，不是滚动市盈率本身。

| 口径 | 数 | 怎么来的 |
|---|---|---|
| 现价对应市盈率 | | 市值 ÷ 情景利润 |
| 市净率 | | 市值 ÷ 最近报告期归母净资产 |
| 已公告累计归母 | | 覆盖到哪一季 |
| 情景全年归母 | | 已公告 + 未出季度测算 |

高低只相对这个情景。若情景利润偏乐观，同一价格要写成更贵。历史分位放在表下，不拿来下「便宜」的结论。
