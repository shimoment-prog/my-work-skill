# 个股日报

用户说「个股日报」「股票日报」，或要求按这个模版写某只股票时，读本技能和 [reference.md](reference.md)，按 [template.md](template.md) 现取数、现填表。不要靠对话记忆里的旧数字。同一只股票若已有 `report/{code}-日报-*.md`，沿用五段，只刷新当天的数。

## 何时使用

- 要一份个股日报，而不是行业综述
- 要求先判断估值高低，再给走势情景、股价带和概率
- 要求「按模版出数据」，或更新上一份个股日报
- 要求先画今年各季归母和同比、预测季，再画今年和去年的归母总和

已有专用日报的标的仍走专用技能：长江电力用 `cypc-daily-brief`，五粮液用 `wuliangye-daily-brief`，比特币用 `btc-daily-brief`。

版式样例：章节和利润图对照 `/Users/richao11/myproject/my-quant/report/catl-日报-2026-10-21.md`。股价带对照 `/Users/richao11/myproject/my-quant/report/sungrow-日报-2026-10-21.md`，四条都是区间。只对照写法，不沿用里面的价格和利润。

## 产出

每次都写两份（本地，未要求则不 commit）：

1. Markdown：`/Users/richao11/myproject/my-quant/report/{code}-日报-YYYY-MM-DD.md`
2. Canvas：`/Users/richao11/.cursor/projects/Users-richao11-myproject-my-quant/canvases/{code}-daily-YYYY-MM-DD.canvas.tsx`

章节顺序固定，不要增删、不要调换：

1. 当前估值：高还是低
2. 未来走势：情景、股价带、对应什么、概率
3. 归母：今年各季与同比、预测季，再给今年和去年的总和
4. 要关注什么
5. 近期重要信息：行业政策、公司公告、提示风险和利空

回复用简体中文。先给一句话结论，再给路径链接。文末写「不构成投资建议」。

把 [template.md](template.md) 的占位符换成当天核过的数。

## 取数顺序

```
进度:
- [ ] 现价、昨收、总股本、总市值，写明时点
- [ ] 最近已公布的归母、扣非、毛利率
- [ ] 今年已公告各季归母和同比，未出季度单独测算
- [ ] 去年全年总和、今年已公告总和、今年含测算的总和
- [ ] 用情景利润 × 倍数 ÷ 股本框出股价带，写成区间。同一只股票已有上下沿就沿用
- [ ] 近期行业政策、公司公告、风险和利空。没有新事实就写没有，不编
```

## 硬规则

- 未公布的季度利润不要写成已公告。测算用另一种颜色，图下写假设。
- 估值高低对着写明的利润情景，不对着历史高点。历史市盈率分位单独一句，不代替高低判断。
- 概率是判断，四条加总约 100%。每条写对应的利润或倍数。不写成统计模型的输出。
- 股价带写成区间，不写成一个点。口径见 [reference.md](reference.md)。同一只股票已有上下沿就沿用，只改现价落在哪一档、概率怎么挪。倍数变了要说明。不把区间写成目标价。
- 不给买卖建议，不把股价带写成目标价。
- 第五段只写已公布的政策、公告和公司自己的说明。媒体转述要标明。没有新公告就写没有。券商目标价不写进这一段。

## Canvas

只从 `cursor/canvas` 导入。无渐变、无 emoji、无阴影。一句话 Callout + 五段。提到 canvas 时用完整绝对路径 markdown 链接。

利润图两张，对齐长江电力：

1. **今年各季**：横轴四个季度。去年各季用 `neutral`，今年已公告用 `info`，预测季用 `warning`。表上写今年归母和同比。未披露季度的 0 是占位，图注写明不表示利润为零。
2. **总和**：去年全年、今年已公告累计、今年含预测季的全年。预测不并进已公告那根柱。

纵轴是归母净利润，单位亿元。不要只画同比。不回溯到前年的每个季度。
